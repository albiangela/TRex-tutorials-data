TRex Setup and Resources

1. Installation Instructions

Follow these simple steps to install TRex:

  1. Install Miniforge
    Download Miniforge from conda-forge.org/miniforge.
    2. How do I open the Miniforge terminal and what is a terminal?

    A terminal (or command-line interface) is a text-based tool for interacting with your computer. Here’s how Miniforge integrates with your terminal:

    • Windows: Use the Miniforge PowerShell terminal from the Start menu.
    • macOS/Linux: Open your Unix terminal. You may need to manually activate Miniforge as described during installation.
  2. Create a TRex Environment
    conda create -n track -c trex-beta trex
  3. Activate the Environment
    conda activate track
  4. Launch TRex
    trex

You are now ready to use TRex. For support, visit the TRex documentation or GitHub repository.
